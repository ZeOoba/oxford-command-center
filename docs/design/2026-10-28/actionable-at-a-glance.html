Command Center: what needs you, visible in five seconds

I audited the shipped shell, Overview, alerts and primitives. The IA is in good shape now. The remaining problem is signal placement: the most actionable content sits below descriptive charts, the rail never tells you where the trouble is, and numbers arrive without a target to judge them against. Below: ten findings, a clickable redesign, and the order I'd ship it in.

01

What I found

10 findings · each tied to the file it lives in
01

The most actionable widget is third

high

Overview opens on 8 KPI tiles, then a Results banner, then NOI-by-market and Top tenants. Priority Actions is half-width and usually below the fold.

overview/widgets.tsx · OVERVIEW_WIDGETS order
Open on a verdict line + "Do next" list; charts move down or behind Edit layout.
02

One feed, rendered three ways on one page

med

Results banner, Priority Actions and Insights each call mergeInsightSources(). Alerts, Brain › Insights and Digest are three more homes for overlapping items.

ResultsBannerWidget · PriorityActionsWidget · InsightsWidget · AlertsModule
One ranked list. Overview shows the top N; each destination shows the same feed scoped to itself.
03

KPIs have no reference point

high

Value, NOI, SF, Occupancy, WALT, Debt, Equity, Cash are absolute numbers. Nothing says whether 93.1% is good. Four of eight are descriptive and never change a decision.

KpiStripWidget · KpiStat has delta but no target
Six target tiles: value, bullet bar with plan tick, colored variance.
04

The rail is silent

high

Badges exist only on tabs (Alerts, Rent roll, Feedback). To learn Property Condition has an over-reserve roof you have to open it.

Sidebar.tsx NavItem · tab-badges.ts
Lift the existing tab-badge hooks to the rail: count, $ or dot.
05

Status shown four times, top bar has 11 controls

med

StatusPill, HealthDot, StaleBanner and AlertBell all report system or attention state. "As of" is hidden below 1400px, which is exactly where laptops live.

TopBar.tsx · StatusPill · HealthDot · StaleBanner
One status pill (freshness + health). Theme, density, scenario go into settings. As-of always visible.
06

Alert cards have five equal buttons and no verb

med

Draft · View · Snooze 7d · Snooze 30d · Mark read, all ghost buttons of the same weight. No due date or owner on the card.

AlertsModule.tsx toTierItem() · TierBoard TierCard
One primary verb per row ("Draft offer", "Start appeal"); the rest live in the detail drawer.
07

Dollars are text, not shape

med

Impact is a mono number in a card corner. Severity columns split the ranking three ways, so #1 overall can sit in column two.

TierBoard columns={3} · formatImpact()
A single ranked list with proportional $ bars; severity is a color, not a column.
08

No view of which property is off, on what

high

The charts slice by market, tenant and month. Nothing crosses property × dimension, which is how an asset manager actually scans.

NoiByMarketWidget · TopTenantsWidget · CashTrendWidget
A property heatmap: occupancy, NOI vs budget, rollover, capex, tax, collections.
09

Filter bar takes a row on every page

low

It shows even where it doesn't apply, and the manager dropdown is permanently empty (NO_MANAGERS = []).

AppShell.tsx FilterBarWithSlice · PortfolioFilterBar
Make it a chip in the page header, only on property-scoped destinations. Hide manager until data exists.
10

Destinations open with no summary

med

Leasing lands on the Rollover chart; Capital on Allocation. You read a panel before you know whether anything is wrong.

Destination.tsx · each module's first TabPanel
Shared header: one-line verdict, 3 KPIs, then the top 3 actions for that destination, then tabs.
