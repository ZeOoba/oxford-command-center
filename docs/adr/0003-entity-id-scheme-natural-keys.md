# ADR-0003: Entity identity uses natural keys, not surrogate autoincrement synced across PM platforms

**Status:** Proposed — must be finalized before Phase 0's E0.1 schema ships; this is the single most expensive-to-reverse choice in the whole platform.

## Context

ORA's entities are already identified inconsistently across four PM platforms (Yardi, AppFolio, Rent Manager, QuickBooks Desktop) plus Notion and HubSpot. A naive autoincrementing surrogate key generated by whichever system ingests a record first is fragile — the same tenant or property can arrive from two sources with no natural way to detect they're the same entity, and re-keying after thousands of facts/edges reference an ID is a system-wide migration.

## Decision

Entity identity is anchored on natural keys wherever one exists and is stable: property = normalized street address; entity/LLC = EIN or, absent that, the ratified legal name; tenant = normalized legal name + property (a tenant can recur across properties as distinct tenancies); vendor = EIN or normalized legal name + address. A surrogate `entity_id` is still generated for join performance, but it is *derived deterministically* from the natural key (a stable hash), never assigned by insertion order — so two independent pipelines extracting the same real-world entity always converge on the same ID without a separate reconciliation pass.

## Consequences

- Requires a normalization function per entity type (address normalization is the hardest — reuse whatever the existing warehouse's PM-platform adapters already do for property matching, don't reinvent it).
- Entities without a clean natural key (e.g., a vendor known only by a first name in an old invoice) get flagged as `identity: unresolved` rather than forced into a bad match — an unresolved entity is safer than a wrongly-merged one.
- This must be settled and tested (E0.1's acceptance criteria) before any document ingestion begins in Phase 2 — every fact and edge written after that point encodes this scheme, and undoing it means re-deriving identity for every historical fact.
